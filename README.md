## 🚀 Установка

1. Установите Python 3.10+ 
2. Клонируйте репозиторий
3. Установите зависимости

```bash <!-- Блок кода -->
git clone https://github.com/user/devdiary.git
cd devdiary
pip install -r requirements.txt
```
